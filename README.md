# 🇨🇱 División de Cuentas - Fiestas Patrias en Familia

Aplicación web interactiva para la división justa, transparente e inteligente de gastos de Fiestas Patrias.

📱 **Enlace público para celulares y computadores:**  
👉 **[https://iamv96.github.io/division-fiestas-patrias/](https://iamv96.github.io/division-fiestas-patrias/)**

---

## 🌟 Características Principales

- **📱 Diseño 100% Responsivo:** Optimizado para que cada familiar pueda revisar su desglose cómodamente desde su smartphone.
- **🔄 Matriz Interactiva en Tiempo Real:** Permite activar o desactivar el consumo de cualquier integrante en cada producto, recalculando cuotas al instante.
- **💳 Cobranza y Tarjetas Individuales:** Tarjeta detallada para cada familiar con el desglose de lo que consumió, estado de pago (Pagado / Pendiente) y recordatorio personalizado.
- **📲 Envío Directo a WhatsApp:** Genera mensajes formateados para compartir resúmenes individuales o del grupo con un solo clic.
- **📊 Análisis & Gráficos:** Visualización de la distribución del gasto y aportes por categoría.
- **💾 Datos Bancarios Personalizados:** Permite configurar y guardar la cuenta de transferencia en el dispositivo.
